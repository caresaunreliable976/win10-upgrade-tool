## 🛠️ Troubleshooting  

**The download doesn’t start?**  
- Try right‑clicking the download button and selecting **“Save link as…”**  
- Use a different browser (Edge, Chrome, Firefox all work).  
- Disable any download manager extensions temporarily.  

**I get a “Windows protected your PC” warning when running the .exe**  
- This is a SmartScreen warning common for unsigned tools.  
- Click **“More info”** → then **“Run anyway”**. The tool is safe and malware‑free.  

**The tool won’t open or crashes on launch**  
- Make sure you extracted the **entire** ZIP folder – don’t run the .exe from inside the compressed file.  
- Right‑click the `.exe` and select **“Run as administrator”**.  
- Temporarily disable antivirus software (re‑enable after use).  

**My PC fails to upgrade or gets stuck**  
- Ensure you have at least 10 GB free space (the tool will warn you).  
- Disconnect external drives and USB devices.  
- Restart your PC and try the **“Repair Installation”** option instead.
